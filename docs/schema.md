# Shared Data Contracts & Event Schema

This document specifies the shared data contracts for the `ebpf-stalls` project. All components (Workload Harness [T1], eBPF Collector [T2], Feature Correlator [T3], and Evaluator [T4]) must adhere strictly to these schemas.

---

## 1. Global Invariants
- **Clock Source**: All timestamps (`ts_ns`, `start_ns`, `end_ns`) MUST use **`CLOCK_MONOTONIC`** in nanoseconds. In Linux eBPF, `bpf_ktime_get_ns()` matches `clock_gettime(CLOCK_MONOTONIC)`.
- **Run Identifier**: Every run is tagged with an immutable `run_id` (e.g., `run_tune_directio_c1_001`).
- **Trace Startup Filtering Rule**: Events emitted prior to the workload process's successful `execve` (`layer=1, syscall_nr=59, ret=0`) represent collector setup/fork overhead and MUST be discarded by the correlation engine (T3).

---

## 2. Collector Raw Events: `events.csv`

Generated by `tracer/collector`. Header row is always present.

### Column Specification

| Column | Type | Description |
|---|---|---|
| `ts_ns` | `uint64` | Monotonic timestamp in nanoseconds (`bpf_ktime_get_ns`) |
| `pid` | `uint32` | Thread Group ID (TGID / Process ID) |
| `tid` | `uint32` | Thread ID (TID) of the tracked thread |
| `layer` | `uint16` | Event source layer: `1` = Syscall, `2` = Scheduler, `3` = Block I/O, `4` = IRQ / SoftIRQ |
| `type` | `uint16` | Layer-specific event type (see matrix below) |
| `syscall_nr` | `uint32` | Syscall number (layer 1) or softirq vector (layer 4) |
| `ret` | `int64` | Syscall return value (layer 1 exit), block error code (layer 3 complete), or softirq duration_ns (layer 4 exit) |
| `prev_state` | `int64` | Task state upon leaving CPU (layer 2 switch_out only, see states below) |
| `sector` | `uint64` | Starting storage sector (layer 3 only, 0 otherwise) |
| `dev` | `uint32` | Target storage device identifier (`dev_t` major:minor, layer 3 only) |
| `nr_bytes` | `uint32` | Transfer size in bytes (layer 3 only, 0 otherwise) |
| `cpu` | `uint32` | Logical CPU / core executing the probe (`bpf_get_smp_processor_id`) |
| `target_tid` | `uint32` | Sched wakeup: waker TID; Block I/O: submitter TID attributed via `bio_submitters` |
| `rwbs` | `string` | Block I/O operation flags: `R`, `W`, `RA`, `WS`, etc. (layer 3 only) |

### Layer & Type Encoding Matrix

#### Layer 1: Syscalls (`layer = 1`)
- `type = 0` (`SYS_ENTER`): Syscall entry. Records `syscall_nr`.
- `type = 1` (`SYS_EXIT`): Syscall exit. Records `syscall_nr` and `ret`.

#### Layer 2: Scheduler (`layer = 2`)
- `type = 0` (`SCHED_SWITCH_OUT`): Tracked thread leaving CPU.
  - `prev_state = 0` (`TASK_STATE_RUNNABLE`): Preempted while runnable (CPU contention / time-slice expired).
  - `prev_state = 1` (`TASK_STATE_INTERRUPTIBLE`): Voluntary sleep (locks, futex, select, timers).
  - `prev_state = 2` (`TASK_STATE_UNINTERRUPTIBLE`): Involuntary wait / disk I/O stall (`D` state).
- `type = 1` (`SCHED_SWITCH_IN`): Tracked thread scheduled onto CPU.
- `type = 2` (`SCHED_WAKEUP`): Tracked thread woken and placed onto runqueue.
  - `tid`: The thread that was woken.
  - `target_tid`: The waker thread (currently on-CPU caller).

#### Layer 3: Block I/O (`layer = 3`)
- `type = 0` (`BLOCK_RQ_ISSUE`): Request submitted to block device. `target_tid` contains submitting TID looked up via `(dev, sector)` from `bio_submitters`.
- `type = 1` (`BLOCK_RQ_COMPLETE`): Block request completed. `target_tid` contains submitting TID.
- `type = 2` (`BLOCK_BIO_QUEUE`): Bio submitted by application thread before elevator queueing.
- *Attribution Note*: `block_bio_queue` records the requesting application thread TID into BPF map `bio_submitters` keyed by `(dev, sector)`. When requests are later dispatched or completed by worker threads (`kworker`), the submitter TID is preserved in `target_tid`.

#### Layer 4: IRQ / SoftIRQ (`layer = 4`)
- `type = 1` (`SOFTIRQ_EXIT`): Softirq execution completing on CPU while a tracked thread was interrupted.
  - `syscall_nr`: Softirq vector number `vec` (e.g., `4` = `BLOCK_SOFTIRQ`, `3` = `NET_RX_SOFTIRQ`, `1` = `TIMER_SOFTIRQ`).
  - `ret`: Elapsed execution time `duration_ns` spent servicing the softirq.

## 3. Workload Ground Truth & Metadata

### Run Manifest: `run.json`
Written by T1 before executing a trial:
```json
{
  "run_id": "run_tune_coldread_c1_s42",
  "workload": "cold_read",
  "io_mode": "O_DIRECT",
  "file_size_mb": 64,
  "concurrency": 1,
  "cache_state": "cold",
  "cpu_contention": false,
  "seed": 42,
  "kernel": "6.8.0-138-generic",
  "device": "nvme0n1p6",
  "split": "tune"
}
```

### Operation Ground Truth: `truth.jsonl`
Appended by T1 instrumented workloads per logical operation:
```json
{"run_id": "run_tune_coldread_c1_s42", "op_id": 1, "tid": 1042, "start_ns": 1710000001000000, "end_ns": 1710000001450000, "syscall": "pread64", "bytes": 1048576, "true_label": "IO_WAIT"}
{"run_id": "run_tune_coldread_c1_s42", "op_id": 2, "tid": 1042, "start_ns": 1710000001500000, "end_ns": 1710000001600000, "syscall": "pread64", "bytes": 1048576, "true_label": "WARM_READ"}
```
Valid labels: `IO_WAIT`, `SCHED_WAIT`, `CPU_SYSCALL`, `WARM_READ`, `NEGATIVE_CONTROL`.

## 5. Correlated Features: `features.parquet` & `features.csv`
Constructed by T3 per `op_id` window:
- `run_id` (string): Unique trial identifier
- `op_id` (uint64): Logical operation index
- `tid` (uint32): Tracked target thread ID
- `dur_ns` (uint64): Total operation duration (`end_ns - start_ns`)
- `duration_ms` (float): Duration in milliseconds
- `t_run` (uint64): Estimated time actively executing on CPU
- `t_runnable` (uint64): Time spent runnable on runqueue waiting for CPU
- `t_blocked` (uint64): Total time descheduled off-CPU (`t_iowait + t_other_sleep`)
- `t_iowait` (uint64): Time spent in uninterruptible `D`-state sleep
- `t_other_sleep` (uint64): Time spent in voluntary interruptible sleep
- `softirq_ns` (uint64): Time servicing softirqs that interrupted the target thread
- `med_dur_ns` (float): Median operation duration across the run (robust baseline, L1)
- `mad_dur_ns` (float): Median absolute deviation of duration across the run (L1)
- `spike_score` (float): Normalized robust z-score: `(dur_ns - med_dur_ns) / mad_dur_ns` (L1)
- `block_issues` / `n_blk_req` (uint32): Total block requests issued in window
- `block_completes` (uint32): Total block completions in window
- `n_blk_direct` (uint32): Block requests directly attributed to target TID via `bio_submitters` (L4)
- `n_blk_bg` (uint32): Background block requests not attributed to target TID (L4)
- `total_block_bytes` / `blk_bytes` (uint64): Cumulative bytes transferred in block layer
- `blk_overlap_frac` (float32): Fraction of stall window overlapping with active block I/O
- `n_ctx_switch` (uint32): Total context switches during window
- `sleep_state_frac` (float32): Ratio of uninterruptible sleep to total off-CPU time
- `evidence_flags` (uint32): Bitmask of diagnostic flags (1: block, 2: runqueue, 4: D-state, 8: on-CPU >= 0.75, 16: direct block, 32: softirq)
- `label_valid` (uint8): 1 if trace signatures match ground truth label, 0 if anomalous (L6)
- `mismatch_reason` (string): Description of signature anomaly if `label_valid == 0` (L6)
- `true_label` (string): Ground truth label
- `label` (string): Normalized label

## 6. Model & Rule Predictions: `pred_<method>.jsonl`
Written by T3 classification models (heuristic rules, decision tree, logistic regression):
```json
{"run_id": "run_tune_coldread_c1_s42", "op_id": 1, "pred": "IO_WAIT", "conf": 0.94, "method": "fused_rules", "est_stall_ns": 420000}
{"run_id": "run_tune_coldread_c1_s42", "op_id": 2, "pred": "INDETERMINATE", "conf": 0.38, "method": "fused_rules", "est_stall_ns": 0}
```
*Note*: If `conf` is below the frozen threshold $\tau$, `pred` MUST be set to `INDETERMINATE` (abstain class).
